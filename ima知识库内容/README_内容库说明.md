# valorantHeroKnow — 无畏契约补位急救内容库

本知识库是「补位急救站」（WeGame Agent 个人 AI 作品 Demo）的内容源，供产品侧经 ima OpenAPI 检索。

## 库结构

- **英雄条目**（规划 10 个，当前 7 个）：每个英雄一个条目，含定位、Q/C/E/X 技能速记、速记提示、教学视频链接（已覆盖 2 决斗者 + 1 哨卫 + 4 先锋）
- **地图条目**（7 张图）：每张图一个条目，含特点一句话、本图速记提示、攻略视频链接
- **社群投稿**（当前 2 条：1 条样例 + 1 条端到端实测）：玩家在工作台提交的技巧，经人工审核后追加入库（条目名带「社群投稿」前缀），入库闭环已实测通过

## 来源标注规范（重要）

每个条目必须标注内容来源，二选一：

| 来源 | 标注值 | 适用内容 |
|---|---|---|
| **官网 / 官方整理** | `source: official` | 英雄技能数值、官方 Wiki 说明、官方教学视频链接——由官方源整理入库 |
| **用户上传** | `source: user` | 玩家/UP主投稿的技巧，经人工审核后入库 |

**用户上传条目必须保存以下元数据**（随条目一起写入 ima）：

| 字段 | 说明 |
|---|---|
| `user_id` | 投稿用户ID（Demo 阶段为匿名 ID，接入账号体系后为登录 ID） |
| `ts` | 投稿时间 |
| `likes` | 点赞数（随投稿动态更新） |
| `comments` | 评论列表（作者 / 内容 / 时间） |
| `author` | 显示署名 |

官方条目（`source: official`）不要求上述元数据。

## 使用方式

产品端通过 ima OpenAPI 检索：例如识别到英雄「捷风」+ 地图「亚海悬城」时，检索对应两个条目组装 30 秒速记卡；检索社群投稿条目时，可依据 `source` 字段区分官方内容与玩家经验，展示时给玩家标注来源。
